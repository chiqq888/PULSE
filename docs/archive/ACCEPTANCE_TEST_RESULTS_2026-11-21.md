## หมายเหตุด้านขอบเขตที่ต้องสื่อสารตอนนำเสนอ

- ระบบใช้ JSON Server `0.17.4` เป็น Mock REST API สำหรับสาธิตตามลำดับ จึง **ไม่ได้รับประกันการป้องกัน race condition แบบ atomic** หากมีหลายเครื่องลงทะเบียนหรือเช็กอินพร้อมกันในเวลาเดียวกัน
- 0 Console Errors และ 0 Uncaught Page Errors ตลอดการทดสอบทั้ง 84 ขั้นตอนในเบราว์เซอร์จริง
